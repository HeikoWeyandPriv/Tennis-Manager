# Glossar

| Begriff                  | Bedeutung                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| **Ankunft**              | Erster Schritt der Schlagauflösung: wie gut ein Spieler den Ball erreicht (bequem, unter Druck, knapp, nicht erreicht).  |
| **Ansichtsmodus**        | Legt fest, welche Punkte animiert werden: alle Punkte, nur entscheidende Punkte, Games überspringen.                     |
| **Aufschlagmix**         | Verteilung der Aufschlagtypen Power, Kick und Slice (zusammen 100 %), getrennt für 1. und 2. Aufschlag.                  |
| **Ausführung**           | Dritter Schritt der Schlagauflösung: Qualität des Schlags (Fehler, schwach, solide, stark).                              |
| **Changeover**           | Seitenwechsel; Zeitpunkt, an dem Tendenzen angepasst werden, Energie regeneriert und Momentum abklingt.                  |
| **Einstand**             | Stand im Game, wenn beide Spieler mindestens 40 haben und gleichauf liegen; zum Gewinn braucht es zwei Punkte Vorsprung. |
| **Energie**              | Vorrat an Kraft für das Match. Sinkt durch Schläge, Laufwege und Taktik; regeneriert teilweise in Pausen.                |
| **Erzwungener Fehler**   | Fehler bei einer Ankunft unter Druck oder knapp.                                                                         |
| **Game**                 | Aufschlagspiel im Satz, gezählt mit 0, 15, 30, 40, Einstand und Vorteil. Ein Tiebreak zählt als ein Game.                |
| **Momentum**             | Gemeinsamer Tauziehen-Wert zwischen beiden Spielern; beeinflusst leicht alle Attribute.                                  |
| **Satz**                 | Folge von Games; gewonnen mit der festgelegten Zahl Games und zwei Games Vorsprung, sonst entscheidet der Tiebreak.      |
| **Satzpause**            | Pause nach einem Satz, wenn das Match noch läuft; wirkt wie ein Changeover, regeneriert aber mehr Energie.               |
| **Schlagauflösung**      | Die vierstufige Regelkette für jeden Schlag: Ankunft, Schlagwahl, Ausführung, Übergabe.                                  |
| **Schlagmix**            | Grundpräferenz für die Schlagtypen Power, Topspin, Slice, Stop und Lob (zusammen 100 %). Keine direkte Häufigkeit.       |
| **Schlagwahl**           | Zweiter Schritt der Schlagauflösung: Auswahl von Schlagtyp und Zielzone.                                                 |
| **Situationsfilter**     | Regel, nach der die Situation bestimmt, welche Schlagtypen überhaupt sinnvoll sind, bevor der Schlagmix greift.          |
| **Spielerposition**      | Standort eines Spielers in Tiefe (weit hinter Grundlinie, Grundlinie, Mittelfeld, Netz) und seitlich.                    |
| **Tendenz**              | Taktik-Regler, der Wahrscheinlichkeiten verschiebt, aber keine Schläge erzwingt.                                         |
| **Tiebreak**             | Entscheidungsspiel bei Gleichstand der Games im Satz; bis zur festgelegten Punktzahl mit zwei Punkten Vorsprung.         |
| **Übergabe**             | Vierter Schritt der Schlagauflösung: Der Ball landet in der Zielzone, der Gegner ist dran.                               |
| **Unerzwungener Fehler** | Fehler bei bequemer Ankunft.                                                                                             |
| **Vorteil**              | Stand im Game nach einem Einstand: Ein Spieler hat einen Punkt mehr und gewinnt das Game mit dem nächsten Punkt.         |
| **Winner**               | Punktgewinn, weil der Gegner den Ball nicht erreicht.                                                                    |
| **Zählformat**           | Parameter, die festlegen, wie ein Match gezählt wird: Gewinnsätze, Games pro Satz, Tiebreak-Punkte. Variiert je Match.   |
| **Zielzone**             | Eines von 3 × 3 Feldern pro Platzhälfte (links/Mitte/rechts × kurz/mittel/tief).                                         |
